# ADR-003 — Earned Evolution Is Distinct from Motivational Renewal

**Status:** Accepted

## Decision
Low-adherence refreshes are Motivational Renewals, not earned progression.

## Rationale
Users should not remain trapped in one program forever, but calling a low-adherence refresh a conquest would devalue genuine consistency.

## Consequence
Motivational renewal does not increment Intermediate promotion credit and should not award earned-evolution XP/achievement semantics.
