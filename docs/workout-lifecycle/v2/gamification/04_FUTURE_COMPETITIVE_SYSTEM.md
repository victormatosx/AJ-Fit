# Future Competitive System

**Status:** TARGET_SPEC
**Implementation:** NOT IMPLEMENTED — no leaderboard, ranking, or challenge system exists. Entirely out of Fase 5's scope.

Future AJ Fit competition may aggregate XP from many domains: workouts, physical assessments, progress sharing, challenges, consistency and other verified actions. Workout lifecycle is only one producer.

The competitive system must define anti-abuse rules, event verification, reward caps, seasons/rankings and privacy separately. This specification intentionally does not assign XP values or ranking formulas.
