# Same-Level Cycle Rotation

**Status:** TARGET_SPEC
**Implementation:** PARTIAL — exercise substitution rotation is implemented (`evolveCycle`, ADR-008); "controlled ordering within compatible groups" is deliberately NOT implemented in Phase 3 (no reordering at all, see ADR-008's ordering decision).

Same-level evolution exists to renew motivation without arbitrary difficulty escalation.

Target: modify approximately 20–30% of the program while preserving level, goal, frequency, split and approximately equivalent volume. Allowed changes include equivalent exercise variations, controlled ordering within compatible groups, and small set redistribution.

Rotation must be deterministic/auditable enough to explain what changed and must avoid immediately cycling back to the exact prior variation when alternatives exist. Random same-muscle replacement is not acceptable.
