# Beginner → Intermediate

Beginner is an adaptation level, not an endless cycle system. Target duration is approximately one active month. Expected sessions derive from prescribed frequency; eligibility requires ≥70% valid prescribed sessions and the minimum active-time gate.

A user who misses the target remains Beginner until the required adherence is reached or a separate future product rule explicitly handles prolonged low adherence. Promotion is earned, automatic at the domain level, and produces an Intermediate prescription using the user's current goal, availability, environment and safety constraints. StartingLevel remains Beginner for history.
