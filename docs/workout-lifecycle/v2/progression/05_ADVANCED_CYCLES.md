# Advanced Cycles

**Status:** TARGET_SPEC
**Implementation:** PARTIAL — the unbounded `EVOLUTION_ELIGIBLE` decision (never `LEVEL_PROMOTION_ELIGIBLE`, proven for cycles up to 100 in the resolver test matrix) is implemented; controlled-variation re-prescription is not.

Advanced has no terminal cycle. Earned cycles continue indefinitely. The system must avoid monotonic complexity, volume or difficulty escalation. Each new cycle preserves the level's technical intent and uses controlled variation to create freshness and perceived progress.

Advanced cycle numbers are durable career history. A re-prescription can restart the current ProgramInstance period without erasing completed Advanced cycles.
