# Motivational Renewal

Purpose: prevent a low-adherence user from remaining on the exact same program indefinitely and becoming more disengaged.

After the normal cycle window has been substantially exceeded (target starting point: roughly 30 additional active days) while adherence remains below the earned threshold, AJ Fit may offer/trigger a refreshed same-level program.

This is **not** an earned evolution: it does not increment Intermediate promotion credit, should not use congratulatory level-up language, and should not award evolution XP. Copy should frame it as a fresh start to help regain rhythm. The refreshed program may use the same controlled 20–30% rotation rules.
