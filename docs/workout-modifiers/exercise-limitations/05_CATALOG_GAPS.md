# Catalog gaps

## Definição DR-019

Status: `RESOLVED`.

Um `CATALOG_GAP` só existe quando um slot necessário, após auditoria de todos os
116 exercícios, não possui candidato canônico que satisfaça simultaneamente:

- função/padrão e músculo primário necessários;
- ambiente e equipamento real;
- todas as limitações;
- safety e complexidade;
- availability/status;
- adaptation rules executáveis.

Antes de criar exercício, registrar template/sessão/slot, original, contexto,
candidatos avaliados e reason code de cada rejeição. Mudança no resolver,
inventário do questionário ou metadata deve ser considerada antes de conteúdo
novo. Novo exercício exige ID, traduções pt-BR/en/es, schema completo e revisão.
